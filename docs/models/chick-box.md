# Chick Treat Box

Animal-box family member (Easter). **Same body, lid, fold animation and
printable-face pipeline as the [Bunny Treat Box](bunny-box.md)** — see the
**[animal-boxes playbook](../animal-boxes.md)**. Only the ears and face differ.

- **Model:** `src/core/models/chickBox.ts` (spec) on `animalBox.ts` · **id:** `chick-box`
- **Category:** party · **Status:** built (folds + opens/closes in 3D)

## What's different from the bunny

- **"Ears":** a small **3-feather tuft** at the top centre (flat top either side).
- **Face (4 recolourable groups):** `body` (a yellow rounded face patch + a fill
  on the tuft), `eyes` (dark discs), `beak` (an orange triangle), `cheeks` (rosy
  discs).

Everything else is the family default.
