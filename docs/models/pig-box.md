# Pig Treat Box

Animal-box family member. **Same body, lid, fold animation and printable-face
pipeline as the [Bunny Treat Box](bunny-box.md)** — see the
**[animal-boxes playbook](../animal-boxes.md)**. Only the ears and face differ.

- **Model:** `src/core/models/pigBox.ts` (spec) on `animalBox.ts` · **id:** `pig-box`
- **Category:** party · **Status:** built (folds + opens/closes in 3D)

## What's different from the bunny

- **Ears:** two **small triangles**, tips leaning slightly outward.
- **Face (5 recolourable groups):** `ears` (pink inner triangles), `eyes` (dark
  discs), `snout` (a pink oval — the pig's signature), `nostrils` (two dark
  ovals on the snout), `mouth` (a stroked smile). Order: snout before nostrils so
  they sit on it.

Everything else is the family default.
