# Dog Treat Box

Animal-box family member. **Same body, lid, fold animation and printable-face
pipeline as the [Bunny Treat Box](bunny-box.md)** — see the
**[animal-boxes playbook](../animal-boxes.md)**. Only the ears and face differ.

- **Model:** `src/core/models/dogBox.ts` (spec) on `animalBox.ts` · **id:** `dog-box`
- **Category:** party · **Status:** built (folds + opens/closes in 3D)

## What's different from the bunny

- **Ears:** two **floppy rounded ears** leaning outward (Q-curve lobes).
- **Face (5 recolourable groups):** `ears` (inner-ear ovals), `muzzle` (a light
  oval the nose/tongue sit on), `eyes` (dark discs), `nose` (a dark oval), `tongue`
  (a pink oval hanging below the nose). Order: muzzle before nose/tongue.

Everything else is the family default.
