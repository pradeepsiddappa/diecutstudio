# Owl Treat Box

Animal-box family member. **Same body, lid, fold animation and printable-face
pipeline as the [Bunny Treat Box](bunny-box.md)** — see the
**[animal-boxes playbook](../animal-boxes.md)**. Only the ears and face differ.

- **Model:** `src/core/models/owlBox.ts` (spec) on `animalBox.ts` · **id:** `owl-box`
- **Category:** party · **Status:** built (folds + opens/closes in 3D)

## What's different from the bunny

- **Ears:** two pointed **feather tufts**, leaning outward.
- **Face (5 recolourable groups):** `tufts` (brown inner-tuft triangles), `discs`
  (two big tan facial discs — the owl's signature), `eyes` (white discs),
  `pupils` (big dark discs), `beak` (an orange triangle between the eyes). Order:
  discs → eyes → pupils so the big eyes layer correctly.

Everything else is the family default.
